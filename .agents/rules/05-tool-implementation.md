# Tool Implementation

- No fake or placeholder implementation marked as complete
- No new dependency without license and maintenance review
- Client-side processing preferred when technically possible
- Every tool must have its own SEO route
- Every tool must use the Result Workspace
- Processing mode must be correctly classified: client, server, hybrid, or research-required
- Difficult features must be honestly documented (PDF text editing, PDF-to-Office, handwriting OCR, media processing)
- Licensing-sensitive features must be flagged
