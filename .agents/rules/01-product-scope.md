# Product Scope

- **Identity**: OmniFexa product identity and positioning.
- **Core Rules**:
  - No compulsory login for free tools
  - Browser-first processing
  - Mobile+desktop parity
  - SEO per tool
  - No fake reviews/ratings
  - No thin SEO pages
  - Privacy-first
  - Screenshot editing is flagship
  - Must not facilitate document fraud
- **Result Workspace**: Every processed output opens in Result Workspace before export.
- **Result Workspace Adapters**: pdf, image, text, code, simple, media, whiteboard.
