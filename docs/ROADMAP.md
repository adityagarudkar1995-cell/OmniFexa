# Development Roadmap

## Phase 1: Foundation (COMPLETED)
- Project setup & strict Next.js 16 scaffold
- Design system scaffolding & theme management (light/dark/system)
- Production-ready homepage & hero search
- Canonical catalog (187 tools) with validation scripts
- Tool Platform Shell (`/tools` catalog & `/tools/[slug]` pre-rendered static routes)
- Universal Result Workspace contracts, capability registry & visual shell preview
- SEO indexing guardrails (noindex for planned tools, sitemap exclusion)

## Phase 2: Core Launch (NEXT)
- Basic PDF tools (compress, merge, split)
- Image tools (compress, resize, crop, format conversions)
- Screenshot editor MVP (flagship)
- Text tools, Calculators, Developer tools, Converters/Generators
- *Goal: Establish initial user base with solid, fast client-side tools.*

## Phase 3: Document Workflows
- PDF editing, viewing, annotation
- PDF security (protect/unlock)
- PDF form filling, scanning, basic OCR (integration)
- *Goal: Become a reliable document hub.*

## Phase 4: Advanced Conversion
- PDF ↔ Office format conversions
- Complex image tools (upscaler, background remover, object eraser)
- Advanced PDF operations requiring server processing
- *Goal: Move into high-value operations.*

## Phase 5: AI Tools
- All AI PDF tools (Assistant, Chat, Summarizer)
- Grammar cleanup
- Advanced OCR with AI models (handwriting, multilingual)
- *Goal: Differentiate with intelligent capabilities.*

## Phase 6: Media & Growth
- Audio/video tools
- Whiteboard capabilities
- Growth features (user accounts for saved prefs, history)
- Internationalization
- *Goal: Complete the "Every Tool" vision.*

## Assumptions & Dependencies
- Phase 2 relies heavily on finding performant client-side libraries.
- Phases 4, 5, and 6 depend on setting up scalable backend services and AI inference infrastructure.
- Monetization plans will likely start forming actively between Phases 3 and 4.
