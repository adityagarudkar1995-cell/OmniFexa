# Security and Privacy Policy

## Core Principle
**Privacy-first processing model.**

## Processing Boundaries
- **Client-side default**: Data processing happens locally in the browser whenever feasible.
- **Server processing boundary**: Files are sent to the server *only* when technically required (e.g., PDF-to-Office, AI inference).

## File Handling & Storage
- Files processed on the server are held entirely in memory.
- **No permanent storage**: Files are automatically deleted immediately after processing is complete.
- Content within files is never logged or indexed.

## User Authentication
- Authentication is completely optional and never required for free tools.

## Data Retention
- Data retention policies are minimal and clearly communicated to the user at the point of action.

## Infrastructure Security
- **HTTPS everywhere**: Strict transport security.
- Content Security Policy (CSP) headers implemented to prevent XSS.

## Ethical Usage
- OmniFexa tools must not be designed or marketed to facilitate document fraud (e.g., creating fake IDs or forging signatures).
