# Design System Brief

## Direction (Not Implementation)
This brief outlines the aesthetic and structural guidelines for OmniFexa's UI.

## Color System
- **Dark Mode Primary**: The default, offering a sleek, premium, and focused environment.
- **Light Mode Secondary**: Clean and accessible fallback.
- Avoid generic colors; use curated, harmonious palettes (e.g., HSL tailored colors).

## Typography
- **Geist Sans** + **Geist Mono** (integrated via Next.js).
- Clear heading hierarchy and readable body text.

## Spacing Scale
- Predictable spacing tokens (e.g., 4px, 8px, 16px, 24px) for consistent rhythm.

## Component Principles
- **Mobile-first**: All components must look and function perfectly on mobile screens before desktop enhancements are applied.
- **Accessible**: ARIA labels, semantic HTML, and high contrast ratios.
- **Consistent**: Reusable styles over one-off adjustments.

## Animation Principles
- **Subtle**: Micro-interactions for hover states and transitions.
- **Purposeful**: Animations should guide the user's focus, not distract.
- **Performant**: Rely on CSS transforms and opacity for 60fps rendering.

## Icon System Direction
- Unified stroke width and style across all icons (e.g., Lucide or Phosphor).

*(Note: No specific component implementations have been built yet.)*
